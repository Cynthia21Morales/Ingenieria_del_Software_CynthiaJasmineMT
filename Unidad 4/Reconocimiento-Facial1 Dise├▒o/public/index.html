Preguntas Generales

El sistema utiliza tecnología de reconocimiento facial avanzada para identificar a los empleados. Captura la imagen facial a través de la cámara y la compara con la base de datos de empleados registrados para registrar entradas y salidas de manera segura y eficiente.

El sistema es compatible con los principales navegadores modernos como Google Chrome, Mozilla Firefox, Microsoft Edge y Safari en sus últimas versiones. Para un mejor rendimiento, recomendamos usar Google Chrome.

El sistema requiere una conexión a internet para funcionar correctamente, ya que necesita acceder a la base de datos y mantener sincronizados los registros. Sin embargo, opera en la red local de la empresa, lo que garantiza mayor seguridad y velocidad.

Puede obtener soporte técnico de varias formas:
  • A través del botón de "Contáctenos" en el menú de soporte
  • Enviando un correo a ciscodedeveloper@gmail.com
  • Consultando esta sección de FAQ

Sí, el sistema implementa múltiples capas de seguridad:
  • Conexión HTTPS encriptada
  • Almacenamiento seguro de datos biométricos
  • Backups automáticos
  • Control de acceso por roles
  • Registro de todas las operaciones

Reconocimiento Facial

Si el sistema no te reconoce, asegúrate de:
  • Tener buena iluminación
  • Estar mirando directamente a la cámara
  • No usar accesorios que cubran el rostro
  • Actualizar tu foto de registro si ha habido cambios significativos en tu apariencia

El reconocimiento facial es casi instantáneo, generalmente toma entre 1-3 segundos. Este tiempo puede variar según:
  • La calidad de la cámara
  • La iluminación del ambiente
  • La velocidad de la conexión
  • El número de usuarios registrados

Por razones de seguridad y precisión, el sistema no está diseñado para funcionar con mascarillas u otros elementos que cubran parcialmente el rostro. Es necesario tener el rostro completamente visible para un reconocimiento exitoso.

Para un óptimo funcionamiento, la cámara debe cumplir con:
  • Resolución mínima de 720p (1280x720)
  • Buena calidad en condiciones de baja luz
  • Enfoque automático
  • Compatibilidad con WebRTC

Registro de Usuarios

Para registrar un nuevo usuario:
  1. Ve a la pestaña "Registro de Usuario"
  2. Completa los campos requeridos (nombre, cédula, departamento)
  3. Toma una foto o sube una imagen del usuario
  4. Haz clic en "Registrar Usuario"

Para actualizar la foto:
  1. Ve a "Gestión de Usuarios" en el menú de configuración
  2. Busca al usuario que deseas actualizar
  3. Haz clic en el botón de editar
  4. Selecciona "Tomar Foto" o "Subir Foto"
  5. Guarda los cambios

Sí, el sistema permite la importación masiva de usuarios:
  1. Ve a "Gestión de Usuarios"
  2. Haz clic en "Importar Usuarios"
  3. Descarga la plantilla Excel
  4. Completa la información en la plantilla
  5. Prepara las fotos en una carpeta
  6. Sube la plantilla y las fotos

Las fotos deben cumplir con los siguientes requisitos:
  • Formato: JPG o PNG
  • Tamaño máximo: 5MB
  • Resolución mínima: 640x480 píxeles
  • El rostro debe ser claramente visible
  • Fondo preferiblemente claro y uniforme

Para eliminar un usuario:
  1. Ve a "Gestión de Usuarios"
  2. Busca al usuario que deseas eliminar
  3. Haz clic en el botón de eliminar (ícono de papelera)
  4. Confirma la eliminación
Nota: Esta acción no se puede deshacer y eliminará todo el historial de asistencia asociado al usuario.

Sí, para cambiar el departamento:
  1. Ve a "Gestión de Usuarios"
  2. Busca al usuario
  3. Haz clic en editar
  4. Selecciona el nuevo departamento
  5. Guarda los cambios
Nota: El cambio de departamento afectará a los futuros registros de asistencia, pero no modificará el historial existente.

Reportes

Para exportar un reporte:
  1. Selecciona el tipo de reporte que deseas
  2. Aplica los filtros necesarios
  3. Haz clic en el botón "Exportar"
  4. Elige el formato de exportación (Excel o PDF)

El sistema ofrece varios tipos de reportes:
  • Informe Diario: Registro detallado de entradas y salidas
  • Asistencia por Departamento: Estadísticas grupales
  • Reporte de Puntualidad: Análisis de tardanzas
  • Horas Trabajadas: Cálculo de tiempo laboral

Puedes filtrar los reportes usando:
  • Rango de fechas
  • Departamento específico
  • Empleado individual
  • Estado de asistencia
Los filtros se pueden combinar para obtener información más específica.

Sí, los reportes se actualizan automáticamente cuando:
  • Se registra una nueva entrada o salida
  • Se modifica información de usuarios
  • Se realizan cambios en los departamentos
También puedes actualizar manualmente usando el botón "Generar Reporte".
